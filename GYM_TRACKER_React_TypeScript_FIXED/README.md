# GYM TRACKER

Современный адаптивный фитнес-трекер на **React + TypeScript + Vite + Tailwind CSS + shadcn/ui-style компонентах (Radix UI) + Lucide React + Recharts**. Не требует регистрации, аккаунта, бэкенда и внешней базы данных. Весь интерфейс — на русском языке.

## Быстрый запуск

Нужен **Node.js 20.19+ или 22.12+** и доступ к npm для первоначальной установки зависимостей.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно `http://localhost:5173`). Сервер здесь — только локальный сервер разработки для статического фронтенда, **сервер приложения и аккаунт не нужны**.

### Продакшен-сборка

```bash
npm run check
npm test
npm run build
npm run preview
```

Статический результат будет в каталоге `dist/`. Его можно разместить на GitHub Pages, Netlify, Vercel, Cloudflare Pages или любом HTTPS-хостинге. Для Netlify/Vercel параметры: **build command** `npm run build`, **publish directory** `dist`.

**Установка на телефон:** открой опубликованный HTTPS-адрес в браузере смартфона → меню браузера → «Добавить на экран Домой» / «Установить приложение». После первой полной онлайн-загрузки сервис-воркер кэширует ресурсы для офлайн-работы. Записи всегда сохраняются локально в браузере устройства. Для переноса на другой телефон используй **Настройки → Скачать резервную копию JSON / Восстановить из JSON**.

## Функции

- Точная предустановленная программа: **ПН (6 упражнений, 16 подходов), СР (7 упражнений, 19 подходов), ПТ (6 упражнений, 17 подходов)**. Понедельник начинается с жима штанги лежа; приложение не меняет порядок автоматически. Отдельные упражнения на заднюю дельту не добавлены.
- Дашборд с ближайшей тренировкой, расписанием, прогрессом активного занятия, объемом, последними результатами и графиком.
- Удобные карточки подходов с весом, повторениями, фактом выполнения, отметкой правильной техники, показателями прошлого раза, добавлением и удалением подходов.
- Автоподстановка рабочих весов с прошлого раза, восстановление черновика после перезапуска, заметки и таймер отдыха 60 / 90 / 120 / 180 секунд.
- Советы по прогрессивной перегрузке: только когда **каждый** подход завершен, достигнут верхний порог повторений и **каждая** отметка правильной техники выставлена.
- История тренировок: подробности, дата, веса, повторения, общий объем, сравнение с предыдущей тренировкой этого дня, редактирование и удаление с подтверждением.
- Recharts: динамика рабочих весов, отдельный график жима лежа, объем, регулярность за 8 недель, подходы по мышечным группам, личные рекорды, недельная и месячная статистика.
- Редактор дней и упражнений: название, расписание, количество подходов, диапазоны повторений, группа мышц, шаг повышения веса, добавление/удаление. Изменения действуют только для новых занятий; архив не переписывается.
- Темная и светлая темы, адаптивное меню, мобильная навигация, PWA-ресурсы, экспорт CSV и резервные копии JSON с импортом.
- Подтверждение удаления тренировки, подхода, упражнения, истории, сброса программы или всего приложения.

## Важные особенности

- В режиме офлайн сохраняются данные и доступны загруженные экраны; публикация PWA требует HTTPS (или localhost).
- История хранится в `localStorage` под ключом `gym-tracker:v1`. Она **не синхронизируется** автоматически между браузерами и может исчезнуть при очистке данных браузера. Делай резервные копии JSON.
- Тренировочный объем = сумма **вес × повторения** только для выполненных подходов. Для подтягиваний с собственным весом можно ставить `0 кг`: собственный вес не прибавляется автоматически.
- Рекомендация повысить вес не заменяет оценку техники и самочувствия.
- Интернет нужен только для первоначальной установки npm-пакетов на компьютере и первой загрузки опубликованной версии. Шрифт Inter при офлайн-работе заменяется системным.

## Структура проекта

```text
src/
  App.tsx                 Главная навигация и жизненный цикл тренировок
  types.ts                Типы упражнений, подходов, истории и приложения
  main.tsx                Точка входа + регистрация service worker
  styles.css              Темы, анимации и глобальные стили
  components/
    ExerciseCard.tsx      Интерактивная карточка упражнения
    RestTimer.tsx         Таймер отдыха
    ConfirmDialog.tsx     Подтверждение опасных действий
    Shared.tsx            Повторно используемые визуальные блоки
    ui/                   Примитивы в стиле shadcn/ui на Radix
  hooks/useAppData.ts     Реактивное localStorage-хранилище
  lib/defaults.ts         План, расчеты, автоподстановка, прогрессия
  lib/storage.ts          Проверка JSON, сохранение, экспорт CSV
  pages/
    HomePage.tsx          Dashboard
    WorkoutPage.tsx       Активная тренировка
    HistoryPage.tsx       История и редактор записей
    ProgressPage.tsx      Аналитика Recharts
    PlanPage.tsx          Редактор программы
    SettingsPage.tsx      Тема, экспорт, импорт, сброс
public/                   Иконки PWA, manifest и service worker
scripts/test-logic.cjs    Юнит-проверки ключевых сценариев
```

## Тесты

```bash
npm test
```

Проверяются исходная программа, точный порядок, числа подходов, сохранение истории, логика прогрессивной перегрузки, расчет объема, автоподстановка, дата ближайшей тренировки, проверка формата JSON и CSV.

**В этом архиве исходный код, а не собранный `dist`.** Установи зависимости и выполни `npm run build`, чтобы получить готовый к публикации статический сайт.
